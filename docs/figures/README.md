# Explanatory manuscript diagrams

The publication-facing explanatory diagrams used by the JISA manuscript are:

- `benchmark_schema.pdf` - benchmark schema and attack/benign example flow;
- `evaluation_workflow.pdf` - end-to-end AlignSec evaluation workflow;
- `system_architecture.pdf` - AlignSec evaluation system architecture.

Editable author-controlled PowerPoint sources are preserved under `source/`:

- `source/benchmark_schema.pptx`
- `source/evaluation_workflow.pptx`
- `source/system_architecture.pptx`

These explanatory diagrams were manually redrawn for publication presentation.
They are not frozen statistical outputs and do not change the study benchmark,
model responses, metrics, statistical analyses, or reported scientific results.
